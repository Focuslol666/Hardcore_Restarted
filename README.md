## Play Now

***Script Here:***

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Focuslol666/Hardcore_Restarted/refs/heads/main/Scripts/Loader.lua"))()
```

Press the **Q key** or the **GUI button** to enable sprint.

The script must be executed at **Door 0** or an error will occur.
